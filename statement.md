# Project Statement
## Problem Statement
Manual student evaluation can make record management, result calculation, ranking and reporting repetitive and error-prone. This project provides a structured system for these tasks.
## Scope
Student CRUD, marks validation, evaluation, ranking, queries, reports and JSON storage.
## Target Users
Students, teachers and academic staff.
## High-Level Features
Student management, marks evaluation, CGPA calculation, pass/fail evaluation, ranking, queries, reports, validation and persistent storage.
